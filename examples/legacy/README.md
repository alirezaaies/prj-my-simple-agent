# Original tutorial scripts / کدهای آموزشی اولیه

## English

These are the original scripts preserved before refactoring. They document the learning path and are not the maintained launchers. They do not load `.env`, require manually installed dependencies, and use relative state files. Use `run_agent.py` from the project root instead. Original private `memory.json` and `tasks.json` remain at the root and are ignored by Git.

## فارسی

این فایل‌ها نسخهٔ اولیهٔ کدهای شما هستند و برای حفظ مسیر یادگیری نگه داشته شده‌اند. نسخهٔ قابل استفاده و نگهداری از `run_agent.py` اجرا می‌شود. کدهای قدیمی `.env` را نمی‌خوانند و مسیر حافظهٔ آن‌ها به پوشهٔ اجرای ترمینال وابسته است. فایل‌های شخصی قدیمی در ریشه حفظ شده‌اند و وارد Git نمی‌شوند.
